# ① 👨‍🏫 教授办公室：不断修改论文

教授在办公室里**持续不断**改论文：

**continual = 不断的、频繁的**

他发现你的观点跟他的正好**相反**：

**contrary = 相反的**

但你的内容和经济学高度**相关**：

**relevant = 相关的**

于是教授采用一种新方法：

**approach = 方法；接近**

他说研究必须：

**independent = 独立的**

你也要：

**independently = 独立地**

最后得到研究结果：

**obtain = 获得**

并判断方法是否：

**appropriate = 合适的**

### 🧠 一条电影

> continual 修改 → contrary 意见 → relevant 问题 → approach 方法 → independent 研究 → independently 完成 → obtain 结果 → appropriate 方法

# ⚠️ 这些先不要当正常单词背

你原文里的：

**g / x / b / f**

大概率是公式里的**变量或符号**。

**nd / ed / eds / cf / co / con / contra / de / dem / den / di / cher / semi / self**

这里面情况复杂。有些是缩写、前缀、词的一部分，或者是文本提取造成的碎片。例如：

**cf.** 在学术文献中常用于“比较、参见”；
**semi-** = 半；
**self-** = 自我；
**contra-** = 反对、相反。

但是像 **nd / ed / eds / dem / den / di / cher**，如果它们是从电子书/PDF自动提取出来的，我不建议现在花时间背。**需要结合原句才能判断到底是不是独立词。**
